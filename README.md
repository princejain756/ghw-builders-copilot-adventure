# GitHub Copilot Choose-Your-Own-Adventure: Incident Commander

Built for **MLH Global Hack Week: Builders Week** GitHub Copilot challenges:

- **Use GitHub Copilot to Build a Simple Application**: Interactive CLI and Web Choose-Your-Own-Adventure application (`src/adventure.mjs`) where engineers triage a production latency spike in real time.
- **Use GitHub Copilot to complete any of this week's challenges**: Used GitHub Copilot to scaffold, debug, and verify our Builders Week applications.

## Quick Start

```bash
# Run the CLI adventure
npm run cli

# Launch the web interface on http://localhost:4579
npm start
```
